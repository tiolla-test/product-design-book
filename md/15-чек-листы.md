# Приложение Б. Чек-листы

## Постановка задачи

- [ ] Проблема описана через последствие для бизнеса и человека
- [ ] Названы пользователи и роли
- [ ] Есть главная метрика и контрольные метрики
- [ ] Известен базовый уровень или способ его получить
- [ ] Ограничения записаны с источником
- [ ] Есть раздел «Что не делаем»
- [ ] Открытые вопросы собраны и у каждого есть кто решает

## Сценарий и состояния

- [ ] Сценарий начинается с цели человека
- [ ] Показаны все развилки и возвраты
- [ ] У каждого экрана есть пустое, частичное, ошибочное состояние и ожидание
- [ ] Статусы не обгоняют реальность, у статуса одна точка правды
- [ ] Нет дат и сроков, которых никто не назначал
- [ ] Проверены вопросы «а что, если участников двое», «а что, если человек вышел посреди», «а что, если удалить»
- [ ] Модель данных проверена на нескольких пользователях и объектах

## Экран

- [ ] Одна главная задача и одна главная кнопка
- [ ] Фокус совпадает с главным действием (проверка размытием)
- [ ] Отступы кратны шагу сетки, близкое сгруппировано
- [ ] Шрифт и цвет по ролям, у роли один вид
- [ ] Красный только для ошибки и опасного действия
- [ ] «Отмена» нейтральная, опасное действие тише главного
- [ ] Цвет проверен на том фоне, где будет жить
- [ ] Экран просмотрен целиком на десктопе и телефоне

## Доступность

- [ ] Контраст текста 4,5 : 1, крупного текста и элементов 3 : 1
- [ ] Всё доступно с клавиатуры, фокус виден, порядок логичный
- [ ] Окна закрываются по Esc, фокус возвращается
- [ ] Кликабельное сделано кнопкой или ссылкой
- [ ] У каждого поля видимая подпись, ошибки связаны с полями
- [ ] Цвет дублирован текстом или иконкой
- [ ] Цели касания не меньше 44
- [ ] Уважаются «Уменьшить движение» и «Уменьшить прозрачность»

## Тексты

- [ ] Важное в начале, одна мысль в предложении
- [ ] Кнопки называют действие глаголом
- [ ] Ошибка говорит, что случилось и как исправить
- [ ] Нет слова «успешно» и восклицательных знаков
- [ ] Статус называет состояние с точки зрения человека
- [ ] Одно слово на одну вещь, совпадает со словарём
- [ ] Кавычки «», даты в нужном формате, «вы» с маленькой буквы

## Прототип и проверка

- [ ] Правка выпущена новой версией, есть строка в журнале
- [ ] Новая версия собрана из последней рабочей
- [ ] Пройдены все состояния, включая редкие
- [ ] Снимки на нескольких ширинах
- [ ] Проверка проверена нарочной поломкой
- [ ] Подозрительные находки проверены вручную
- [ ] Результат просмотрен глазами

## Готовность к передаче в разработку

- [ ] Спецификация описывает значения токенами и логику условиями
- [ ] Все состояния и крайние случаи описаны
- [ ] Тексты всех строк, включая ошибки
- [ ] Точки перелома и что меняется на каждой
- [ ] События для метрик
- [ ] Смоделированное без интеграции подписано
- [ ] Открытые вопросы перечислены

## Кейс в портфолио

- [ ] «Коротко» в четыре пункта
- [ ] Роль и масштаб в одной строке
- [ ] Задача через последствие, у частей задачи метрики
- [ ] Развилки «Отказалась / Выбрала» с ценой и источником
- [ ] Своё, общее и чужое раздельно, участие ИИ описано
- [ ] Цифры с источником, спорных чисел нет
- [ ] Заголовки называют тему
- [ ] Есть «Что не сделано» и «Что сделала бы иначе»
